# 🍳 OpenFood Restaurateur — Portail Partenaire

Interface dédiée aux restaurateurs partenaires pour la gestion quotidienne de leurs commandes et de leur carte.

## 🌟 Fonctionnalités Clés
- **Commandes en Direct :** Réception instantanée des commandes entrantes avec signal sonore d'alerte, estimation du temps de préparation, modale d'acceptation ou de refus.
- **Gestion du Menu :** Ajout de plats, descriptions, prix, photos, catégories et déclinaisons d'options.
- **Inventaire & Disponibilité :** Activation/désactivation en 1 clic de la disponibilité des articles pour éviter les ruptures en plein service.

## 🚀 Lancement
```bash
flutter pub get
flutter run -d chrome
```
